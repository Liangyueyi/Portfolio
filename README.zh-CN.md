### 视觉识别与边缘计算安全系统

**用途：** 面向企业视觉安全场景，覆盖数据标注、模型训练、场景算法、边缘实时分析及告警，并根据不同企业需求完成部署与交付。

**架构：** 数据与标注层 → 模型训练及算法层 → 边缘推理与视频接入层 → 事件判定及告警服务 → 监控展示与历史记录。数据侧组织样本、标注和数据集格式转换；模型侧训练检测模型并开发场景算法，导出适配部署环境的模型；运行侧部署在边缘计算盒子上，接入摄像头视频流并在盒端执行解码、预处理、模型推理与事件判定，将识别结果转换为业务事件和告警。

**边缘盒子部署与适配：** 根据不同企业使用的边缘计算盒子，开展设备调试与运行适配，涉及后摩、算能、取心等平台。适配工作覆盖设备运行环境、推理 SDK 与驱动、模型格式及转换、视频接入和告警链路联调，重点校对输入尺寸、预处理、输出解析与实际场景结果。模型、算法服务和配置部署在对应盒端，结合设备资源与运行条件进行调试。

**零代码自动标注与训练平台：** 作为同一项目的配套平台，为甲方提供可视化操作入口，将自动标注、数据集处理、模型训练及输出流程封装为业务功能。使用者通过界面完成流程配置与操作，无需直接编写训练脚本。平台层连接标注与训练能力，处理后的数据进入模型训练流程，模型输出衔接后续边缘部署与场景应用。

**模块协作：** 平台侧组织数据准备与模型训练，算法侧处理场景识别与事件规则，边缘侧负责视频分析与推理执行，服务与展示侧提供告警触发、图片展示和历史查询。不同企业对应同一系统的应用场景及交付配置；AI 实验室、标注中心和相关工业智能化建设方案作为该项目的配套规划，不单独列为项目。

**个人贡献：** 参与系统的数据标注与部分场景算法编写，完成不同企业边缘计算盒子的调试与适配；独立完成面向甲方的零代码自动标注与训练平台开发。整套视觉安全系统的主体架构及其他核心模块由合作开发者完成，本人贡献范围为上述参与开发及独立开发部分。

### 医院设备管理与质量控制系统

**用途：** 面向科室设备巡检、故障上报、工程师处理和质控追踪，支持用户加入多个组织并切换使用。

**架构：** 微信小程序与管理 Web 端 → FastAPI → 异步 SQLAlchemy / PostgreSQL。Redis 缓存组织上下文，ASR 与大模型辅助语音填报，Word / Excel 服务生成报表。核心数据按组织隔离，通过成员角色控制操作权限。

**模块协作：** 用户登录并选择组织后，接口在组织和成员角色范围内访问设备、巡检、故障与审计记录。语音先由 ASR 转写，再结合组织设备清单和多层热词纠正生成结构化填报内容；业务变更使相关上下文缓存失效。故障从上报、分派和处理进入闭环，报表服务读取同一业务数据生成导出文件。

**个人贡献：** 独立开发应用系统，完成组织权限、设备业务、故障闭环、语音填报与报表集成。

### 弈标 AI 智能标书工作台

**用途：** 将招标解析、目录组织、企业资质匹配、商务标与技术标撰写、文档组装及 Word 输出组织为可编辑工作流程。

**架构：** React / TypeScript 工作台 → FastAPI 业务接口 → 解析、资质、撰写与导出服务 → SQLAlchemy / SQLite。前端通过分步向导确认解析范围、投标主体和章节目录；后端连接 Dify 解析工作流与 LLM，分别处理招标要求提取、章节生成、资质分类和方案摘要。资质库维护企业、证照、业绩、人员与产品资料，方案库管理参考文档；文档服务通过 python-docx 等组件完成字段填写、图片附件组装和排版导出。

**数据流程：** 招标文件上传 → 结构化要求与目录确认 → 关联投标主体及资料 → 分章节生成和人工编辑 → Word 组装输出。项目记录关联解析产物、章节与材料，支持继续编辑；回归代码覆盖向导、具体业务样本和文档输出。

**个人贡献：** 独立开发前后端、文档处理流程、模型集成与业务验证。

### Windows AI 桌面助手

**用途：** 在 Windows 桌面提供语音对话、记忆、工具调用、桌面操作与编程项目工作模式。

**架构：** .NET / WinUI 3 主界面与悬浮界面 → Host 进程管理数据、策略和调度 → Python Sidecar 处理本地唤醒、VAD 与向量能力；Agent、浏览器和 Windows 设备操作按工作进程分工，通过 MCP 扩展工具。模型与语音服务支持流式交互。

**模块协作：** Bootstrap 统一启动并管理子进程；Host 维护角色数据、历史、调度和工具权限，WinUI 主壳与悬浮窗提供入口。Sidecar 提供本地唤醒、语音活动检测与向量检索，AgentWorker 返回工具计划；BrowserWorker 与 Windows DeviceAgent 承担浏览器及桌面执行。角色独立存储，凭据使用 Windows DPAPI 加密，MCP 服务承担外部能力扩展。

**个人贡献：** 独立开发桌面应用与系统集成，组织多进程生命周期、对话、工具、记忆及安装发布流程；复用的外部组件与模型归原作者。

**相关插件开发：** 在 AI Agent Harness 中独立开发和集成人设、跨会话记忆、语音及桌面操作扩展。插件连接唤醒、VAD、ASR 转写与朗读链路，将语音送入当前工作区会话，并提供桌面工具、人工接管、安装校验及回滚。该插件是基于已有产品的扩展工作，作为桌面 AI 方向的补充经历展示。

### 动册 AI 管理系统

**用途：** 面向企业日常经营的 AI 业务管理工作台，通过自然语言调用业务工具，组织客户跟进、审批流、会议纪要、经营周报和现金流分析等业务模块，并生成 Word、PDF、PPT 及 Excel 交付物；支持本地与云端模型及多平台部署。

**个人贡献：** 参与系统开发与功能迭代，承担模型接入、插件与工具能力集成、文档处理、跨平台运行及部署验证等工作。

### 机场屏幕操作合规审查

**用途：** 读取机场业务系统的屏幕内容，识别操作状态、参数及步骤，审查操作过程是否符合规定要求，并提供异常提示与复核依据。

**参考实现架构：** 屏幕采集与窗口定位 → 图像预处理及感兴趣区域提取 → OCR / 控件状态识别 → 页面状态与操作事件生成 → 流程状态机及规则引擎 → 异常提示、证据留存与审查记录。以下按正式系统需求给出可实现的参考设计，用于说明完整技术路径，具体组件与历史实现尚待核对。

- **采集与界面定位：** 通过屏幕捕获或窗口采集接口读取目标应用，记录画面时间戳；依据窗口边界、界面锚点或模板定位业务区域，处理分辨率、缩放及窗口移动带来的坐标变化。采集驱动负责画面接入与状态检测，不直接代替业务规则判定。
- **文字与状态识别：** 对目标区域进行裁剪、缩放和对比度处理，通过 OCR 提取参数、运行模式和提示文本，通过模板匹配或视觉识别判断按钮、选项及确认状态。结果整理为字段值、页面类型、识别置信度及原始画面引用。
- **事件与流程建模：** 对连续画面去重并比较状态变化，将稳定的界面变化转换为参数设置、页面切换、确认完成等事件。采用多帧确认和超时处理减少闪烁、弹窗及短暂识别误差的干扰；状态机维护当前步骤与允许的下一步。
- **合规规则判断：** 按任务场景配置步骤顺序、前置条件、参数范围、组合约束和完成条件。规则引擎关联识别事件与当前流程，检查漏步、顺序错误、参数不符及超时；识别不充分时标记待核验，避免直接判定操作违规。
- **服务与数据管理：** 采集识别进程向审查服务提交结构化事件，后端管理任务、流程模板、规则版本与审查结果。事件和判定记录写入数据库，异常截图按任务归档；界面展示当前步骤、异常依据和复核结果，记录所用规则版本以支持追溯。

**个人贡献：** 独立开发正式系统，围绕屏幕读取与操作规范审查完成业务实现。另有基于 React 的操作流程 Demo，用于模拟规定区域与点击顺序；该 Demo 与正式识别审查系统分别展示。
